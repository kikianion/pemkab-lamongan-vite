# Pemkab Lamongan – Mobile Home (React + Vite)

    npm install
    npm run dev      # development
    npm run build    # production build -> dist/

Structure: `src/App.jsx` (state), `src/components/*` (Header, MapSection, LifeCycle, ServiceCards, TabBar, Sprite icons), `src/data.js` (stages, cards, pins), `src/assets/*` (map SVG + portraits).
Edit pin positions in `src/data.js` (`left` / `top` in %).
